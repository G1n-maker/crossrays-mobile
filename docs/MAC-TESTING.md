# 在 Mac 上测试 Cross Rays

## 启动

```bash
./play.sh
```

**不限时长。** 结束方式：
- **关掉游戏窗口**（红色按钮）
- 或在终端里按 **Ctrl-C**

日志写到 `./logs_play.txt`。

---

## 完整键位表

Switch 手柄有 16 个按钮 + 2 个摇杆，键盘全部映射到了。

### 正面按键

| Switch | 键盘 | Cross Rays 作用 |
|---|---|---|
| **A** | **J** | 确认、选择、推进对话 |
| **B** | **K** | 取消、返回 |
| **X** | **U** | 打开菜单 |
| **Y** | **I** | 信息、单位详情 |

### 肩键（你问的）

| Switch | 键盘 | Cross Rays 作用 |
|---|---|---|
| **L** | **Q** | 左切页、上一个单位 |
| **R** | **E** | 右切页、下一个单位 |
| **ZL** | **Z** | 左扳机（缩放、次要功能） |
| **ZR** | **C** | 右扳机（缩放、次要功能） |

### 方向 / 摇杆

| Switch | 键盘 | Cross Rays 作用 |
|---|---|---|
| **十字键 ↑↓←→** | **方向键 ↑↓←→** | 选菜单、移动光标 |
| **左摇杆** | **W A S D** | 移动单位（八方向） |
| **右摇杆** | **Shift + 方向键** | 转视角、滚地图 |
| **按下左摇杆（L3）** | **F** 或 **G** | — |
| **按下右摇杆（R3）** | — | 未映射 |

> 右摇杆要注意：**先按住 Shift，再按方向键**。松开 Shift 前，方向键是右摇杆；松开后回到十字键。

### 系统键

| Switch | 键盘 | Cross Rays 作用 |
|---|---|---|
| **＋** | **Return** | 主菜单、回合结束 |
| **－** | **Tab** | 地图、辅助信息 |
| **Home** | — | 未映射（不需要） |
| **截图** | — | 未映射 |

> **空格** = 摇晃（体感），Cross Rays 用不到。

### 记忆口诀

```
右手确认取消：J 确认  K 取消
左手移动：      WASD
切页：          Q 左  E 右
扳机：          Z 左  C 右
菜单：          Return
```

## 测试顺序

按这个走最容易发现问题。

### 1. 标题画面
- 背景图完整吗？（应有高达和宇宙背景）
- 菜单文字正常吗？
- BGM 有吗？

### 2. 新游戏 → 序章
- 剧情对话能推进吗？（`J` 连按）
- **立绘**、对话框背景正常吗？
- 语音有吗？

### 3. 主菜单（`Return`）
- 各项图标正常吗？
- 光标移动、选中效果对吗？
- 试着用 `Q` / `E` 切页

### 4. **进战斗**（最关键）
- 3D 地图渲染正常吗？（地形、网格）
- **机体模型有贴图吗**？（不是白模或纯色）
- 移动、攻击动画正常吗？
- 战斗特效（光束、爆炸）有吗？
- 用 **Shift+方向键** 转视角试试
- 帧率稳定吗？（窗口左上角有 FPS 数字）

### 5. 存档
- 能存档吗？
- 退出再进能读档吗？

## 发现问题时怎么报告

最有用的三样：

**1. 症状** — 越具体越好
> ✅ "机体是纯白色，没有贴图"
> ❌ "画面有问题"

**2. 时机** — 什么时候开始的
> ✅ "一进战斗就这样"
> ✅ "放完第一个技能后"

**3. 截图** — `⌘⇧4` 框选

日志我自己会看（`logs_play.txt`）。

- 空格键没反应
